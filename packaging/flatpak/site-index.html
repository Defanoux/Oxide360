Install (updates come by themselves)

Install Oxide360

Opens Discover or GNOME Software. After that, new versions show up there like any other update.

Or in a terminal:

flatpak install --user https://defanoux.github.io/Oxide360/Oxide360.flatpakref

Needs Flatpak (already there on Fedora, Mint, Pop!_OS…). The Freedesktop runtime comes from Flathub the first time.

Already installed from a downloaded .flatpak?

Remove that one first (your designs and settings stay), then install as above:

flatpak uninstall --user io.github.Defanoux.Oxide360

Update by hand

flatpak update io.github.Defanoux.Oxide360

Source, releases and bug reports: github.com/Defanoux/Oxide360
